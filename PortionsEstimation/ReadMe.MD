# Portions Estimation
## Overview
The PortionsEstimation directory includes code for training and evaluating various deep learning models used for food portion estimation.

## Directory Status
- `/src/models`: Contains model definitions, including EfficientNet, Inception, ResNet, and UNet architectures.
- `/src/training`: Includes all training and evaluation routines for the models.
- `/src/data`: Provides dataset setup and preprocessing logic.
- `/notebooks`: Includes notebooks that were used for visualizations, data preprocessing and project log tracking.
